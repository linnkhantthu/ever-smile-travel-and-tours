# Ever Smile Static Website

Plain HTML + CSS + JavaScript website created from the supplied Ever Smile Facebook Page PDF.

## Run locally

Open `index.html` directly, or serve the folder with any static server.

Example:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Deploy

Upload the contents of this folder to GitHub Pages, Cloudflare Pages, Netlify, Vercel static hosting, or any normal web host.

## Source

Content and selected photographs were extracted from the supplied Facebook Page PDF captured September 20, 2026. Package availability, prices, dates and inclusions should be confirmed with Ever Smile before publication/booking.
